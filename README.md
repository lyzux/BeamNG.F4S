# Feel4Speed 1.0.0

Feel4Speed is a BeamNG.drive camera mod that adds a stronger sense of speed,
acceleration, braking and cornering while retaining the native camera settings.

- Passive speed-based FOV, vignette, radial edge blur and angular wobble.
- Acceleration/braking FOV kicks and a damped camera-distance spring.
- Independent engine-RPM wobble.
- Lateral-G camera roll, with inward lean by default and an inversion option.
- Separate drift permissions that smoothly fade active cues during sideslip.
- Compact, translucent controls with scrollable Camera, Active, Cornering and
  Effects tabs, automatic saving and configurable presets.

## Install

Remove older Feel4Speed ZIPs, place `feel4speed.zip` in the active BeamNG user
folder's `mods` directory, and restart the game.Add the
Feel4Speed app through UI Apps if needed and select Standard for the full tune.
